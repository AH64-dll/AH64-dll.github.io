AI agents · Browser extension

NAVI

Browser bridge for terminal AI agents

A system that lets a terminal AI agent work safely inside the user's own Chrome browser, built on top of the open-source Pi agent harness.

  • Built the full chain: CLI server, private local socket, native-messaging connector, extension service worker, content script and consent popup.
  • Versioned message protocol with strict runtime validation and fixed size limits, plus an explicit, revocable permission model.
  • 11 automated test suites covering protocol, transport, security and browser logic.
  • TypeScript
  • Node.js
  • Chrome Extensions (MV3)
  • Native Messaging
